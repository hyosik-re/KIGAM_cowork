# 한글 분담 작성 파일럿

설치된 한글에서 항목별 문서를 편집하고 Git으로 이력을 관리하는 시험 구성입니다. 동일 문서의 실시간 동시편집 기능은 없습니다.

현재 이 저장소는 공개되어 있습니다. 사용자가 공개 업로드를 승인한 `templates/데이터관리계획(DMP)_test_data.hwp`만 시험 문서로 포함합니다. 그 외 HWP/HWPX/PDF/DOCX 및 local-only 폴더는 Git 추적에서 제외합니다. .gitignore는 보안 통제가 아니며 강제 추가를 막지는 못합니다. 실제 업무 문서는 비공개 저장소 또는 기관 내부 Git에 배치하세요.

## 구성

| 경로 | 용도 |
|---|---|
| templates/ | 기준 양식 |
| parts/ | 담당 항목별 문서 |
| final/ | 총괄 담당자의 통합본 |
| review/ | 검토 기록 |
| ASSIGNMENTS.csv | 담당자와 진행 상태, 현재는 예시 항목 |
| WORKFLOW.md | 실제 작업 절차 |

아직 문서를 항목별로 분할하거나 여러 PC에서 협업하는 단계는 수행하지 않았습니다. 담당표의 파일명은 계획이며 실제 파일은 없습니다.

## 편집 원칙

- 한 파일은 한 시점에 한 담당자가 편집합니다.
- HWP/HWPX는 바이너리로 취급하고 Git 자동 병합을 사용하지 않습니다.
- 최종 취합과 서식 검수는 설치된 한글에서 수행합니다.
- rhwp는 읽기·텍스트 추출 보조로 제한합니다. 사전 호환성 시험에서 편집 저장 시 메모 손실이 관찰되어 편집·분할·합본 경로에 넣지 않았습니다.

## 공개 승인된 시험 문서

- 파일: `templates/데이터관리계획(DMP)_test_data.hwp`
- 원본 그대로 복사하며 rhwp로 수정하지 않습니다.
- GitHub 업로드 후 별도 복제본의 SHA-256을 비교합니다. 이는 파일 전달 무결성 시험이며 실시간 공동편집이나 서식 편집 호환성 시험은 아닙니다.
